# Тема KovrikiEVA

## Установка
1. WordPress 6.2+, PHP 7.4+.
2. Загрузите `dist/kovrikieva-theme.zip`: «Внешний вид → Темы → Добавить → Загрузить тему» → Активировать.
   При активации тема сама: включит ЧПУ `/%postname%/`, создаст страницы `o-nas`, `fotogalereya`, `otzyvy`,
   `zakazat`, `privacy-policy` (с текстами старого сайта), сбросит правила ссылок.
3. Залейте папку `uploads` в `/wp-content/uploads/` — все фото подтянутся по старым путям.
4. «Внешний вид → Настроить → KovrikiEVA: контакты и интеграции» — телефоны, Viber/Telegram, e-mail для заявок,
   Telegram-бот, Метрика, Google Ads.
5. SEO-плагин (Yoast/Rank Math) **не нужен** — тема выводит title/description/canonical/Schema сама.
   Если плагин всё же стоит, на лендингах тема сохраняет свои мета, на обычных страницах — уступает плагину.

## Где что менять
| Что | Файл |
|---|---|
| Тексты, цены, FAQ, фото лендингов | `inc/data-directions.php` |
| Города (добавить/убрать) | `inc/data-cities.php` |
| Title/description старых URL | `inc/data-seo-legacy.php` |
| Фото работ по маркам | `inc/data-gallery.php` |
| Порядок секций | `landing.php` |
| Стили | `assets/css/main.css` |

После изменения списка городов или направлений правила ссылок обновляются автоматически.

## Адреса
- `/` — коврики ЭВА (Минск), `/{город}/` — ЭВА в городе (старые адреса)
- `/{раздел}/` — лендинг раздела, `/{раздел}/{город}/` — раздел в городе (новые: ворсовые, органайзеры, для дома)
- Карта сайта: `/wp-sitemap.xml` (лендинги — `/wp-sitemap-landings-1.xml`), `/sitemap_index.xml` → 301.
- Заявки: админка → «Заявки».
