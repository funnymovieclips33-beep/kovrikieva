# Переезд kovrikieva.by на новую тему WordPress — этапы

Цель: быстрый (Core Web Vitals «зелёные»), конверсионный сайт на WordPress, **без смены URL**
и без потери позиций, + новые городские страницы по направлениям.

## Этап 1 — Фундамент темы ✅ (готово в этой ветке)
- Тема `theme/kovrikieva` без конструкторов (Oxygen убран), без jQuery, CSS встроен в `<head>`,
  шрифты Roboto / Roboto Condensed локально (4 файла woff2), JS ~6 КБ с `defer`.
- Дизайн в фирменном стиле старого сайта (бордовый `#713939`, Roboto Condensed заглавными).
- Все лендинги из данных (`inc/data-directions.php`): главная (ЭВА), ворсовые, органайзеры (карсбеги),
  для дома, в багажник, в лодку.
- **Старые URL сохранены 1:1**: `/`, `/brest/` … (63 города ЭВА), `/vorsovye-kovriki/`, `/organajzer-v-bagazhnik/`,
  `/dlja-doma/`, `/kovrik-v-bagazhnik/`, `/v-lodku/`, `/zakazat/`, `/o-nas/`, `/fotogalereya/`, `/otzyvy/`, `/privacy-policy/`.
- **Старые title и description перенесены дословно** (`inc/data-seo-legacy.php`, снято с архива сайта).
- **Новые страницы (189 шт.)**: `/vorsovye-kovriki/{город}/`, `/organajzer-v-bagazhnik/{город}/`, `/dlja-doma/{город}/`
  с уникальным блоком по городу/области, своими title/description/H1, перелинковкой по области.
- SEO: canonical, Open Graph, Schema.org (LocalBusiness, Product + AggregateOffer, FAQPage, BreadcrumbList),
  карта сайта WordPress + провайдер для всех лендингов, `/sitemap_index.xml` (старая карта Yoast) → 301 на новую.
- Конверсия: липкая шапка, мобильная панель «Позвонить / Viber / Telegram / Заказать», выбор города,
  формы с маской `+375`, заявки в админку («Заявки») + e-mail + Telegram-бот, цели Метрики
  (`lead`, `form_start`, `call`, `viber`, `telegram`, `open_order`…), конверсия Google Ads.
- Метрика (79743688) и Google Ads (AW-720698988) грузятся отложенно — не влияют на PageSpeed.
- Фото: пути `/wp-content/uploads/...` как на старом сайте — после заливки папки uploads всё подтянется.

## Этап 2 — Контент и конфигураторы
- Пошаговый калькулятор/конфигуратор заказа ЭВА и ворса (цвет материала и канта с превью, подпятник, логотип) — как на старом `/zakazat/`, но с живой ценой.
- Калькулятор для дома/лодки (длина × ширина → цена), загрузка фото схемы.
- Реальные отзывы (карусель с Яндекс.Карт) на лендингах, блок «Нам доверяют».
- Страница «О нас» — усиление E-E-A-T (фото мастерской, команда, сертификаты).
- Уникальные тексты для топ-15 городов по спросу (Гомель, Могилёв, Витебск, Гродно, Брест…) — по данным Вордстата.
- Города для «Коврик в багажник» и «В лодку» (включается одной строкой `'cities' => true`).

## Этап 3 — Миграция без потерь (перед запуском)
- Выгрузить из Яндекс.Вебмастера и Google Search Console **все** URL со входами/показами → сверить с роутами темы,
  для недостающих — 301-редиректы (файл редиректов в теме).
- Установка на тестовый поддомен, закрытый от индексации, проверка всех URL (скрипт-краулер: код ответа, title, H1, canonical).
- Перенос uploads, WebP-версии фото (плагин или конвертация на сервере), настройка кэша страниц (LiteSpeed Cache / Nginx FastCGI) и gzip/brotli.
- Замер PageSpeed / Lighthouse, правки до 90+ на мобильном.

## Этап 4 — Запуск и мониторинг
- Переключение, переобход в Вебмастере и Search Console, отправка новой карты сайта.
- 2–4 недели мониторинга позиций и 404 в Вебмастере, донастройка.
- A/B по первому экрану и формам по данным Метрики (Вебвизор, цели).
